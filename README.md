# OpoPoint 0.1

Primera evolución del prototipo de OpoScope hacia OpoPoint.

## Qué incluye
- Diseño Mobile First.
- Radar visual.
- Buscador en tiempo real.
- Filtros por provincia y estado.
- Tarjetas de procesos.
- Ficha detallada en modal.
- Datos separados de la interfaz (`data.js`).
- PWA básica (`manifest.webmanifest`).
- Primera tanda de procesos reales de Policía Local de Andalucía, con enlaces a BOE/BOJA y fuente de detección OpoBusca cuando están disponibles.

## Cómo probarlo

Abre `index.html` en un navegador moderno. Si el navegador bloquea la carga local de `data.js`, sirve la carpeta con cualquier servidor estático local.

## Próximo paso
Mover `data.js` a una base de datos gratuita y conectar la interfaz a ella sin cambiar la experiencia de usuario.
